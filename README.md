# pubg-map-assets

Updated PUBG map renders for maps reworked since [pubg/api-assets](https://github.com/pubg/api-assets) stopped
being updated (its map images are from patch 31.2, Oct 2024). Same file names and layout as
`pubg/api-assets/Assets/Maps`, so they are drop-in replacements. Used by
[@professor_xan/pubg-replay](https://www.npmjs.com/package/@professor_xan/pubg-replay).

| File | Size | Notes |
| --- | --- | --- |
| `Assets/Maps/Rondo_Main_High_Res.png` | 8192×8192 | Rondo after the 42.2 rework, with labels |
| `Assets/Maps/Rondo_Main_Low_Res.png` | 819×819 | Same, low resolution |

Source: [trevoedwards/pubg-api-assets@7c3dc70](https://github.com/trevoedwards/pubg-api-assets/commit/7c3dc70e79cc42a060e293f6ca86c9804a9c8ef9).
There is no updated render without labels.
